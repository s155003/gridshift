The curve is the Great Britain–trained model applied to this region's live weather and rescaled to its published annual average. The shape — when the clean hours fall — is the useful part; treat the absolute level as an estimate, not a measurement.

    How this works

    Great Britain is one of the very few grids on Earth that publishes an open, real-time, 48-hour carbon-intensity forecast. Where that feed is available GridShift uses it directly.

    Everywhere else the page runs a gradient-boosted model — trained on 8,640 hours of real GB grid data paired with reanalysis weather — directly in your browser, on a live weather forecast. 400 decision trees, evaluated client-side. There is no backend.

    The scheduler is a deterministic optimiser: a sliding-window search for jobs that must run in one block, and an exact dynamic program for splittable jobs with a minimum block length. It low-pass filters the forecast before selecting hours, which counters the optimiser's curse — picking the cheapest individual hours otherwise systematically selects the hours the model most under-predicts.

    Data: National Grid ESO Carbon Intensity API · Open-Meteo. Both free and key-less. Source and full evaluation: GitHub.
